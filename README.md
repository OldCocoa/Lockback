# Lockback
Lockback brings back the iOS 9 lock screen to iOS 10.x.

# What's implemented?
- Basic lock screen elements (Time and date, slide to unlock)
- Small lock screen details (Grabbers, including camera grabber)
- Authentication (Passcode and Touch ID)
- Notifications list
   - Notifications can be buggy, as of now, "slide to view" is disabled due to various crashes with authentication and some other bugs. All of these issues will be fixed in a later build of the tweak.

# What needs to be implemented?
- Media player for content
   - Lockback currently hides the default media player, leaving nothing behind. The old media player will be implemented in a later build of the tweak.

If you find any issues with the tweak, feel free to report it in the Issues tab at the top of this page.
